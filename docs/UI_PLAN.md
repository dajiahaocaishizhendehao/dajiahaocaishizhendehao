# UI 更新方案

- 版本：0.1
- 状态：已确认，P0 实施中
- 更新日期：2026-11-17
- 目标：让系统的信息架构与交互更符合使用逻辑

## 一、核心原则

1. **一处入口、一处数据**：同类数据只在一个地方出现，不做冗余入口。
2. **列表页统一心智**：每个列表 =「主操作 + 实时搜索 + 筛选 + 导出 + 统一分页」，行操作统一「查看 / 编辑 / 删除」。
3. **详情页就地操作**：编辑、关联、登记都在详情页抽屉内完成，不把用户踢回列表再弹抽屉。
4. **反馈与空态一致**：全局 Toast 统一成功/失败反馈；空态/加载态/错误态统一组件。

## 二、信息架构与导航

侧边栏重排为：

```text
总览      工作台
知识产权  全部知识产权（页内 专利/软著/商标 类型筛选）
档案      材料中心
          日期与提醒（列表 + 日历 双视图）
财务      费用台账
          发票台账（新增）
配置      基础资料
          系统管理
```

- 商标合并进「全部知识产权」，删除独立「商标 / Logo」菜单与 `/trademarks` 路由。
- 发票新增独立页 `/invoices`。
- 顶栏后续可加全局搜索（P2）。

## 三、分模块改造

### 工作台
- 快捷入口补全：新建专利/软著/商标、登记费用/发票、上传材料、导入档案。
- 顶部指标卡可点击，跳转到对应列表并带筛选条件。

### 全部知识产权（含商标）
- 商标并入，页内按类型筛选。
- 新建/编辑抽屉支持三种类型的完整字段（专利、软著、商标）。
- 行操作补「删除」，工具栏补「导出 CSV/XLSX」。
- 搜索实时防抖、分页统一。

### 档案详情
- 「编辑」改为详情页就地打开编辑抽屉，不再跳回 `/assets?edit=id`。
- 补「操作记录」页签（依赖 `/audit-logs` 支持 `object_id` 过滤）。
- 「相关记录」逐步改为页签，内嵌对应关联列表。

### 材料中心
- 行操作精简为「查看 / 修改 / 删除」，识别入口弱化到查看弹窗或证书扫描件分类。
- 补分类、标识筛选。

### 日期与提醒
- 新增「列表 / 日历」双视图；日历用现有 `/dates` 数据前端渲染，按 `due_date` 分组。
- 逾期红、7 天内橙、正常蓝区分。

### 费用与发票
- 新增发票台账 `/invoices`：列表 +「登记发票」抽屉（复用 InvoiceDialog）。
- 费用台账保留「登记发票」，发票详情跳转发票台账。

### 基础资料 / 系统管理
- 搜索实时防抖、分页统一；操作日志按对象/时间筛选（可选）。

## 四、全局交互规范

1. 搜索：输入防抖 250ms 实时搜索，回车立即触发，保留「重置」。
2. 分页：统一「共 N 条 · 每页 20/50/100 · 上一页 / 第 X 页 / 下一页」。
3. 表格：统一列头、`—` 空值、状态 badge、行操作顺序「查看 → 编辑 → 删除」。
4. 抽屉/弹窗：主操作右下角「取消 / 保存」，保存中禁用；Esc 关闭、遮罩点击关闭。
5. 确认：删除/作废统一 `.confirm-modal`。
6. 空态/加载：统一「暂无数据」与骨架屏，替换纯文本「加载中…」。
7. 反馈：成功/失败统一全局 Toast。

## 六、已确认决策

1. 商标合并进「全部知识产权」，删除独立商标菜单。
2. 发票台账作为独立页 `/invoices`。
3. 日历视图纯前端用现有 `/dates` 渲染，不加后端聚合接口。
4. 继续自绘轻量基础组件，不引入 UI 组件库。

# 知识产权管理系统交互原型

## 打开方式

直接用浏览器打开 `prototype/index.html`。本原型仅使用 HTML、CSS 和 JavaScript，不需要安装依赖或启动后端服务。

## 原型范围

左侧导航包含 16 个桌面端可切换入口：

1. 工作台；
2. 全部知识产权；
3. 专利档案；
4. 软著档案；
5. 商标 / Logo；
7. 材料中心；
9. 日期台账；
10. 提醒日历；
11. 费用台账；
12. 发票管理；
13. 统计分析；
14. 基础资料；
16. 系统管理。

另有专利/软著共享的档案详情页面，以及以下抽屉或弹窗：

- 新建、编辑专利；
- 新建、编辑软著；
- 新建、编辑商标及Logo图样；
- 登记已授权、已登记、已注册证书；
- 上传材料；
- 新建日期事项；
- 登记费用；
- 登记发票；
- 新增基础资料；
- 文件预览；
- 统计口径说明。

## 推荐评审路径

1. 从“工作台”查看综合信息与快捷操作；
2. 进入“全部知识产权”，搜索 `DEMO-SW`；
3. 点击任意档案的“查看”，切换详情页页签；
4. 打开“材料中心”，预览虚构材料；
5. 查看“日期台账”和“提醒日历”的法律风险提示；
6. 查看“费用台账”“发票管理”；
7. 进入“统计分析”，点击“口径说明”，再切换费用统计；
8. 打开“商标 / Logo”，查看图样卡片、商标详情与类别页签；
9. 打开 `basic-data-v2.html`，评审“基础资料”优化方案。

## 基础资料优化原型

`basic-data-v2.html` 是独立可点击原型，用于评审以下调整：

- 移除“部门”页签与所属部门字段；
- 权利人、人员、代理机构、项目 / 产品统一提供“新建、编辑、删除”；
- “人员”与“系统管理 → 用户”合并展示：姓名、手机、邮箱、状态在此维护，登录账号、角色和密码仍归系统管理；
- 删除采用逻辑删除提示，人员删除后禁止登录，历史记录保留。

> 部门移除会影响现有部门数据范围权限；人员与用户是“共享展示”还是“彻底并表”也尚未确认。两项都需开发前明确。

## 原型边界

- 所有名称、编号、人员、日期、金额和文件均为虚构示例；
- 所有保存、上传、下载、导入和导出操作均为前端演示，不会写入数据；
- 原型没有后端、数据库、真实鉴权、对象存储或官方接口；
- 日期由用户录入，页面不提供法定期限计算或法律结论；
- 费用统计默认口径、到期提醒阈值、角色数据范围、编号规则和文件限制仍待确认；
- 页面中的状态值均标为“示意”，不代表已经确定的数据字典。

## 文件说明

- `index.html`：应用壳、导航、抽屉和弹窗容器；
- `basic-data-v2.html`：基础资料优化方案独立原型（支持 `?tab=persons` 直接查看人员页签）；
- `styles.css`：现代企业蓝桌面端视觉样式；
- `app.js`：虚构演示数据、16 个桌面路由页面和交互逻辑。

当前原型只针对桌面端，建议使用 1366px 或更宽的浏览器窗口。
